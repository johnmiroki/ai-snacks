Read the state, not just the name. stage is what OpenAI calls the feature's maturity; the third column is whether it resolved to on for this machine, which depends on your config.toml, your account and the build's own defaults. Source of truth. Slash-command names and descriptions were read from the running TUI, not from published documentation: build 0.146.0 was driven in a pseudo-terminal, the / picker was opened and paged to its end, and every row it rendered was captured. Subcommands, arguments and launch flags come from codex --help walked recursively over all 68 subcommands on the same build, and the feature table is codex features list verbatim.

Defined is not the same as available. Reading the binary as text turns up slash-command names the picker never offers. That is two different states, and this page separates them by testing rather than assuming. /apps and /debug-config are withheld from the picker but run normally when typed. /rollout, /sandbox-add-read-dir and /test-approval answer Unrecognized command — type "/" for a list of supported commands, which is the identical response a deliberately nonsensical control command got, so they are not registered in this build at all.

Three were not run. /setup-default-sandbox would have reconfigured the sandbox, and the binary labels /debug-m-drop and /debug-m-update DO NOT USE. They are listed as present in the binary and carry a not probed tag; their availability is genuinely unestablished here rather than quietly guessed at.

Where the links go. Each name links to the most specific page that explains it on learn.chatgpt.com/docs — the host OpenAI's Codex documentation moved to, and where the older developers.openai.com/codex/* URLs now redirect. Subcommands link to their own anchor in the developer-commands reference where one exists. A name shown without a link has no official page: those exist only in the build.

One build, one machine. Codex resolves parts of its surface at run time — feature flags, account entitlements, and config.toml all move it. /fast, /memories, /personality, /plugins and /subagents each correspond to a feature flag in the table above, so a build with those switched off will offer fewer commands than are listed here.
