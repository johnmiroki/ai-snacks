/auto-memory — Claude Code vs Codex

Both tools now keep notes on you between sessions, and they went about it in almost opposite ways. Claude Code writes one small file per fact while it works, scoped to the project you are in. Codex sends a separate agent through your session transcripts afterwards and folds what it finds into a single global handbook that the working model is forbidden to edit. This page is each mechanism end to end — where the bytes land, what reaches the model, and what turns it off — read out of the two installed binaries rather than their documentation, then set side by side.

Prompt text belongs to Anthropic and OpenAI respectively and is reproduced here for reference; both change between builds. Where this page and either tool's documentation disagree, this page reflects what the binary contains.

Nothing here was learned by running the tools, and no memory contents from the machine this was written on appear on this page — only the structures both tools define. Claims the binaries do not settle are marked as not established rather than filled in.
